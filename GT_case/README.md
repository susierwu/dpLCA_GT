### to navigate the folders:

- `data` include raw data used to build up base inventories for the garbage truck case study 

- `notebooks` include LCA running notebooks for both the garbage case study, and any additional analysis 

- `prepare_BGDB_veh_ds` include preparing and assigning Technology Readiness Level (TRL) to different future technologies (e.g., batteries) for the garbage truck case study so that the dpLCA can map the future scenario and extract valid technologies to choose from
